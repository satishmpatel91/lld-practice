Bench two

Two ways to add a number

Both reputation bugs in this exercise were arithmetic, both were found by the tests rather than by reading, and both are one token wide.

// addReputation takes a DELTA void addReputation(int delta) { reputation += delta; } author.addReputation(QUESTION_POSTED); author.addReputation(author.getReputation() + QUESTION_POSTED);

The second line passes the current total plus the increment into a method that already does +=, so each post applies the recurrence r → 2r + 1. After n questions the score is 2n − 1 instead of n.

Ten classes, close up

The V2 diagram, same Mermaid source as StackOverflow.md. Ownership runs one way only: a question holds its answers, a post holds its comments and votes, and nothing points back up.

Built as a gated exercise: requirements, naming, design document, V1 without patterns, an argument about whether any pattern was needed, then V2. The Java lives in com.stackoverflow with 47 JUnit tests; the long-form write-up is StackOverflow.md. Concurrency is named as five races and deliberately left uncoded. Reputation on this page uses the same table as ReputationService.
